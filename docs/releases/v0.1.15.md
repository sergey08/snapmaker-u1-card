# Snapmaker U1 Card v0.1.15 — release candidate / candidata

## English

### Changes
- Localized Home Assistant card-picker descriptions in English, Spanish, French, German, Italian, Portuguese and Dutch; unsupported languages use English.
- Localized the empty filament-slot label in all seven supported languages.
- Enabled card-picker preview while keeping initial stub configuration free of temporary preview settings and duplicate card types.
- Reorganized the README with complete English and Spanish sections, documented supported card languages, and constrained the documentation illustration to 600 px in each section.
- Preserved printing, Spoolman, energy charts, camera, and existing stable controls.

### Verification
- Automated card and HACS workflows passed on commit `7ce1ad5` prior to preparing these notes.
- Existing isolated DEV JavaScript is equivalent to this candidate's card JavaScript after development-only element naming; prior user confirmation covered that DEV card, not every locale individually.
- Remaining release gate: visually verify the README illustration in HACS and finish real card-picker/browser acceptance testing. **Do not publish before acceptance.**

## Español

### Cambios
- Descripciones del selector de tarjetas traducidas al inglés, español, francés, alemán, italiano, portugués y neerlandés; si el idioma no está soportado, se utiliza el inglés.
- Etiqueta de posición de filamento vacía traducida a los siete idiomas.
- Vista previa habilitada en el selector sin guardar opciones temporales de previsualización ni duplicar el tipo de tarjeta en la configuración inicial.
- README reorganizado con secciones completas primero en inglés y después en español, idiomas documentados e ilustración limitada a 600 px en ambas secciones.
- Se conservan impresión, Spoolman, gráficos de energía, cámara y controles estables.

### Validación
- Los flujos automáticos de la tarjeta y HACS pasaron en el commit `7ce1ad5`, antes de preparar estas notas.
- El JavaScript DEV aislado es equivalente al candidato excepto en los nombres de elemento; la confirmación DEV anterior no acredita las pruebas individuales de todos los idiomas.
- Pendiente antes de liberar: comprobar visualmente la ilustración en HACS y completar la aceptación del selector en un navegador real. **No publicar sin validación.**
