# Snapmaker U1 Card v0.1.17

## English

### Improvements and fixes
- **Live camera**: display the selected live camera through Home Assistant's native picture-entity component. The camera no longer requires a smart-plug power entity or a specific camera-proxy image format.
- **Spoolman optional**: hide the T0–T3 filament required/remaining weight comparison when no Spoolman spool is associated, while preserving the print status, toolheads, temperatures and controls.
- **Print charts**: when print charts are disabled with `show_print_charts: false`, hide both the charts section and its toggle. When enabled, the existing toggle permits showing or hiding the charts.
- **Power and energy configuration**: remove the in-card power/energy toggle. Add **Show power, energy and costs** to the visual editor under **Display and electricity**. Set `show_energy: false` to hide power, print energy, electricity costs, material costs and total costs. It defaults to visible.
- Keep the regular and compact card layouts, printer actions and existing entity settings.

### Installation
Update **Snapmaker U1 Card** in HACS / Home Assistant Marketplace to **v0.1.17**, then reload the browser. Existing YAML configurations remain compatible. Select your actual power and energy sensors in the editor if you want live measurements; the price sensor is not the power sensor.

### Verification
- Final stable source and release documentation were integrated into `main` after four successful PR checks.
- The user tested the native live camera and no-Spoolman presentation on a second Home Assistant installation.
- The user confirmed the chart-disabled behavior in beta.2 and the editor checkbox in beta.3, as well as the working card layout.
- GitHub automated validation and HACS checks must pass on the final pull-request revision.
- This release does not alter printer firmware or send commands during installation.

## Español

### Mejoras y correcciones
- **Cámara en directo**: se muestra mediante el componente nativo picture-entity de Home Assistant. Ya no depende del interruptor de alimentación ni de una URL de cámara con un formato concreto.
- **Spoolman opcional**: desaparece la comparación de gramos necesarios y restantes T0–T3 si no hay bobinas de Spoolman asociadas, manteniendo el estado, los cabezales, las temperaturas y los controles de impresión.
- **Gráficos de impresión**: con `show_print_charts: false` no aparecen ni los gráficos ni su botón. Cuando están habilitados, se pueden mostrar u ocultar desde la tarjeta.
- **Configuración de potencia y energía**: se elimina el botón de la propia tarjeta. La opción **Mostrar potencia, energía y costes** se encuentra en el editor visual, apartado **Visualización y electricidad**. `show_energy: false` oculta potencia, energía de impresión y costes eléctrico, material y total; por defecto se muestran.
- Se mantienen los modos normal y compacto, las acciones de impresora y los campos de entidades existentes.

### Instalación
Actualiza **Snapmaker U1 Card** a **v0.1.17** desde HACS / Marketplace y recarga el navegador. Las configuraciones YAML actuales siguen siendo compatibles. Para obtener medidas reales configura los sensores de potencia y energía adecuados en el editor; el sensor de precio no mide potencia.

### Validación
- La cámara nativa y la presentación sin Spoolman se han probado en un segundo Home Assistant del usuario.
- El usuario confirmó la ocultación de los gráficos en beta.2 y la casilla de configuración en beta.3, además del aspecto general.
- Las validaciones automáticas de GitHub y HACS deben pasar para la última revisión de la PR antes de liberar.
- La instalación no modifica el firmware ni envía órdenes a la impresora.
