# Snapmaker U1 Card — Release notes

## English
- Print cost breakdown: electricity, estimated Spoolman filament cost and combined total.
- Four-toolhead (T0–T3) filament estimates using slicer data and spool pricing.
- Improved Spoolman inventory and clearer handling of missing prices.
- Preserves existing printer power, LED, camera and print controls.
- Standalone HACS frontend card: no extra backend integration or YAML required.

**Note:** Shared persistent print history is not included. Material costs are estimates until confirmed against a real print.

## Español
- Desglose del coste de impresión: electricidad, material estimado con Spoolman y coste combinado.
- Estimaciones de filamento para los cuatro cabezales T0–T3 mediante datos del laminador y precios de las bobinas.
- Inventario Spoolman mejorado y presentación clara cuando faltan precios.
- Conserva los controles de alimentación, LED, cámara e impresión.
- Tarjeta independiente para HACS, sin integración backend ni YAML adicional.

**Nota:** No se incluye el histórico persistente compartido. El coste de material es una estimación hasta validarlo con una impresión real.
